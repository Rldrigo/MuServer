Servidor MU Online, cliente y codigo fuente.

**[Descargar los paquetes](https://github.com/Rldrigo/MuServer/releases/tag/paquetes-2026-10-12)**

## Archivos de descarga

| Archivo | Contenido |
| --- | --- |
| MuServer.rar | Servidor, herramientas y scripts SQL. |
| Source.rar | Codigo fuente. |
| Cliente.part1.rar | Primera parte del cliente. |
| Cliente.part2.rar | Segunda parte del cliente. |

## Como extraer el cliente

1. Descargar **Cliente.part1.rar** y **Cliente.part2.rar**.
2. Guardar ambas partes en la misma carpeta, sin cambiar sus nombres.
3. Abrir **Cliente.part1.rar** con WinRAR y extraer. WinRAR utiliza la segunda parte automaticamente.

## Antes de usar

Configurar las contrasenas marcadas como `CAMBIAR_ANTES_DE_USAR` y ajustar la configuracion de red y base de datos para tu instalacion.

En los paquetes para publicar se excluyeron respaldos de bases de datos, registros, capturas, archivos temporales de compilacion, claves privadas, archivos `.env` y archivos de cuentas `FakeOnline.xml` y `Xenos-FakeOnline.xml`. Se conservaron los scripts SQL.

Los originales de la carpeta de trabajo se conservaron. Los comprimidos anteriores se excluyeron de estos paquetes para evitar duplicados.
